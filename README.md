# CivicPulse

Municipal complaint intake, triage and operations platform.

> Status: under active development — see the `dev` branch for latest work.

## Problem

Citizen complaints arrive as free text and pile up in an undifferentiated queue.
CivicPulse validates, triages (via a pluggable AI/rules layer), persists, and
surfaces every complaint on a live operations dashboard.
